# Spec Instructions

These instructions are for AI assistants working in this repo.

Always follow the spec workflow in `@/docs/spec/AGENTS.md` when the request:
- Mentions planning/proposals/specs/changes (proposal, spec, change, plan)
- Adds new capabilities or changes existing behavior
- Includes breaking changes (API/schema/contracts)
- Changes architecture/patterns, or behavior-changing performance/security work
- Is ambiguous and needs an authoritative spec before coding

Keep this managed block so it can be refreshed later.
